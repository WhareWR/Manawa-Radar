# Verification and clinical validation

Maintain independent reference measurements for heart rate and respiratory rate. Report errors **and** the proportion of time measurements are unavailable, across sleeping positions, motion, bedding, body types and relevant clinical populations.

Record technical-alarm delivery tests separately from physiological-event detection. Do not infer cardiac arrest from radar signal loss. Clinical emergency detection requires independently justified endpoints, sufficient event data, human-factors testing and regulatory authorization.

Never commit identifiable patient data.
